# UAS X

> 一个用于无人机相关知识学习与日常刷题的 Web App。

UAS X 的目标很简单：把题库、练习、答案解析和复习记录放在一个网页应用中，方便随时刷题，也方便根据自己的学习需要补充题目。

## 主要功能

- **分类练习**：按科目、章节或题型选择练习内容。
- **刷题与背题**：作答后查看答案和解析，或切换背题模式直接复习。
- **多种题型**：支持单选、多选、判断、填空和简答；主观题可对照参考答案自评。
- **模拟考试**：通过计时练习和交卷反馈检查学习情况。
- **错题与收藏**：集中复习错题，收藏需要反复记忆的知识点。
- **题目搜索与笔记**：查找题目，记录自己的理解和易错点。
- **补充题库**：支持导入 TXT、Word（`.docx`）或粘贴试题文本，扩充练习内容。
- **本地记录**：在当前浏览器中保存题库、学习进度及相关设置。

## 实际使用

### 部署 Web App

将仓库提供的 **`UAS-final.zip`** 上传到 [Netlify](https://app.netlify.com/)，创建站点后，打开生成的网站链接即可使用。

如果上传入口要求选择文件夹，请先解压，再上传包含 `index.html` 的站点目录。

### 添加补充题库

1. 在仓库的 **“补充题库文件夹”** 中下载需要的题库。
2. 打开已部署的 Web App，进入 **“导入试题”** 或对应科目的题库导入入口。
3. 上传题库文件，或粘贴试题文本，确认目标分类后完成导入。
4. 检查导入后的题干、选项与答案是否对应，再开始练习。

下载补充题库后，需要手动导入 Web App；仅将文件保存在电脑上不会自动加入练习库。

## 学习记录说明

学习记录保存在当前浏览器的网站本地存储中。请尽量使用同一设备、同一浏览器和同一网站地址继续学习。

更换设备、浏览器或网站地址，不会自动同步原有记录；清除网站数据也可能删除已导入的题库和学习记录。建议保留补充题库的原始文件，便于重新导入。

## 项目实现

项目采用 HTML、CSS 和 JavaScript 构建，通过浏览器运行，可作为静态网站部署。使用现成发布包即可开始刷题，无需自行搭建后端服务。

部分页面样式、图标或文档解析资源可能通过 CDN 加载，使用时建议保持网络连接。

## 题库维护

题库用于学习与复习，内容会随着资料整理和问题反馈逐步补充、修订。题目数量及分类以实际使用的版本和导入内容为准。

发现错误或希望补充题目时，欢迎提交 Issue 或 Pull Request。反馈请尽量包含：

- 所属科目、题目编号或完整题干；
- 存在的问题及建议答案；
- 可核对的资料来源和必要说明。

涉及法规、标准或时效性知识时，请结合最新正式资料核对。本项目题库为学习参考材料，不代表官方考试题库。
